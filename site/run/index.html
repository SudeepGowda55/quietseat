Run it on your own laptop.

Everything below runs on one Mac; it was built and measured on an M1 MacBook Air with 8 GB. You need Node 22.12 or newer, Homebrew, a Discord server you can add a bot to, and either Even Realities G2 glasses with the R1 ring or the Even Hub simulator.

What the glasses app shows while it finds the bot on your laptop

A Discord bot for your server.

In the Discord Developer Portal, create an application, open Bot and copy its token. Under OAuth2, generate an invite link with the bot scope and the View Channels, Send Messages and Connect permissions, and add it to your server. No privileged intents are needed.

Turn on Developer Mode in Discord, right-click your server and copy its ID. The bot captions for the server owner unless you set QS_WEARER_ID to someone else's user ID.

Your bot/.env


      
The pairing token is made in your browser and never sent anywhere. Paste your bot token yourself.

    

  


  

    

      

        
Speech to text, whisper.cpp.

        
The bot expects a whisper.cpp server on port 8178 (change it with QS_WHISPER). The small.en model is about 470 MB and uses about 850 MB of memory once loaded.

        
brew install whisper-cpp
curl -L -o ggml-small.en.bin \
  https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-small.en.bin
whisper-server -m ggml-small.en.bin --host 127.0.0.1 --port 8178 -fa

      

      

        
Reply drafts, llama.cpp.

        
A 1.5B instruct model, 4-bit, about 1 GB. Point QS_LLM at it. Leave it out and the bot uses built-in replies.

        
brew install llama.cpp
curl -L -o qwen2.5-1.5b-instruct-q4_k_m.gguf \
  https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF/resolve/main/qwen2.5-1.5b-instruct-q4_k_m.gguf
llama-server -m qwen2.5-1.5b-instruct-q4_k_m.gguf --host 127.0.0.1 --port 8179

      

    

  


  

    

      
The bot.

      
npm install also applies a one-line patch to @discordjs/voice (discord.js issue #11653) so receiving audio survives end-to-end encryption changes in the call. Join a voice channel and the bot follows you in. It prints the address for the glasses app, with the pairing token in it.

      
git clone https://github.com/SudeepGowda55/quietseat
cd quietseat/bot
npm install
node --env-file=.env src/index.js
# ready; wearer found
# open the glasses app at http://192.168.1.20:5173/?ws=ws://192.168.1.20:8787&token=…

      
The bot's tests run without Discord: npm test.

    

    

      
The glasses app.

      
A Vite app for the Even Hub. Start it, then open the address the bot printed in the simulator, or turn it into a QR code for the Even app on your phone to load on a real G2.

      
cd quietseat/glasses
npm install
npm run dev
# in the simulator
npx evenhub-simulator "<address the bot printed>"
# on real G2 glasses: scan with the Even app
npx evenhub qr --url "<address the bot printed>"

      
Keep the quotes: the address has an & in it. Your phone and laptop must be on the same network.
